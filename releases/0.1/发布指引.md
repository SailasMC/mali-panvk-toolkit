# 如何把这个 0.1 发布出去（网络恢复后）

当前状态：**提交已在本地**（`9ef1b0a`），但手机**连不上 github.com:443**，
所以推送没成功。任选一条通道即可完成：

## 通道 A：手机能直接出海时（最简）

```bash
cd /storage/emulated/0/Mali驱动项目/github-repo
bash dsh-push.sh "release: 0.1"
```

## 通道 B：构建服务器在世时（推荐，服务器是 VPS 能出海）

```bash
cd /storage/emulated/0/Mali驱动项目
# 1) 把仓库送上去
bash 连接服务器.sh push github-repo/mali-panvk-toolkit /root/mali-panvk-toolkit
# 2) 在服务器上推（token 需先放到服务器：/root/.github-token）
bash 连接服务器.sh cmd "cd /root/mali-panvk-toolkit && git push -q https://x-access-token:\$(cat /root/.github-token)@github.com/SailasMC/mali-panvk-toolkit.git sync-main:main"
```

## 通道 C：发 Release 附件（半成品包 18.1 MB）

```bash
# 仓库里已有 releases/0.1/README.md 作为 release 说明；
# 附件用界面拖拽，或（有 token 时）：
curl -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/zip" \
  --data-binary @/storage/emulated/0/Mali驱动项目/release-0.1.zip \
  "https://uploads.github.com/repos/SailasMC/mali-panvk-toolkit/releases/<RELEASE_ID>/assets?name=release-0.1.zip"
```

## 附件里有什么

`release-0.1.zip`（18.1 MB / 22 文件）：最新已打包驱动 APK（v107）、Vulkan 转发垫片、启动器补丁包、
两个驱动 `.so`（v107 打包版 + v129 今夜最后一版）、剪切/三角探针（5 秒复现器）、
驱动侧补丁 4 份、接力卡与交接说明。
